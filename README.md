# 🚀 AI Learning Hub

A modern AI-powered learning platform developed as part of the **Decodelabs Internship Program**. The project provides students with an interactive dashboard, AI assistant, course management, API testing, and profile management in a clean and responsive interface.

---

## 📌 Project Overview

AI Learning Hub is designed to simplify the learning experience by integrating AI-powered features with an intuitive user interface. The platform enables users to access courses, interact with an AI assistant, test APIs, and manage their profiles from one centralized dashboard.

---

## ✨ Features

* 🏠 Responsive Home Page
* 📚 Course Management
* 🤖 AI Chat Assistant

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/AachalBondarde/DecodeLabs-Internship.git
```

Navigate into the project

```bash
cd DecodeLabs-Internship
```

Install dependencies

```bash
npm install
```

Start the server

```bash
npm start
```
